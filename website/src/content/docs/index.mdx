## Try it now

<Tabs syncKey="setup-path">
<TabItem label="Let your agent do it" icon="rocket">

<div class="agent-panel">

<Badge text="Recommended" size="medium" />

**One prompt, zero config work.** Your coding agent downloads the configs, turns on the lints, runs fmt, clippy and cargo-deny, and fixes your code until everything is green.

<Steps>

1. **Copy the prompt**

   ```text title="Prompt" wrap
   Apply the Google Rust Style Guide kit to this repository.
   Follow the instructions at
   https://daniakash.github.io/Google-Rust-Style-Guide/_llms-txt/for-coding-agents.txt
   Then run cargo +nightly fmt, cargo clippy --workspace --all-targets -- -D warnings,
   and cargo deny check bans, and fix what they report without editing the lint configuration.
   ```

2. **Paste it into your agent** from your project root. Works with Claude Code, Codex, Cursor, Gemini CLI, GitHub Copilot and any agent that can run commands.

3. **Review the diff.** Expect new config files, lint tables in `Cargo.toml`, and fixes in your code. The lint configuration itself should match the [downloaded files](/Google-Rust-Style-Guide/config/cargo-lints/) exactly.

</Steps>

</div>

</TabItem>
<TabItem label="Do it yourself" icon="seti:rust">

Run this in a single-crate Cargo project. It adds five files, turns on the lints, and shows you what the guide flags. Existing files are never overwritten.

```sh title="Terminal"
base=https://daniakash.github.io/Google-Rust-Style-Guide/files
for f in rustfmt.toml clippy.toml deny.toml rust-toolchain.toml AGENTS.md; do
  if [ -e "$f" ]; then echo "skipped $f (already exists)"; else curl -fsSLO "$base/$f"; fi
done
curl -fsSL "$base/crate-lints.toml" >> Cargo.toml   # workspaces: see the quick start
cargo clippy --all-targets
```

Using a workspace, or want each step explained? The [quick start](/Google-Rust-Style-Guide/quick-start/) walks through it in four steps with the expected output.

## Every rule has exactly one home

[Google's Rust style guide](https://google.github.io/styleguide/rustguide.html) mixes mechanical rules with design judgment. The kit gives each rule to the cheapest layer that can hold it.

<CardGrid>
  <Card title="Tools enforce" icon="approve-check">
    rustfmt, 41 clippy and rustc lints, and cargo-deny cover **32 of 62** in-scope rules. CI blocks the merge.
  </Card>
  <Card title="Agents follow" icon="rocket">
    `AGENTS.md` teaches Claude Code, Codex, Cursor and others the judgment rules no linter can check.
  </Card>
  <Card title="Humans review" icon="open-book">
    A review guide covers what is left: API shape, ownership design and whether each exception is justified.
  </Card>
  <Card title="Exceptions are written down" icon="pencil">
    Allowed deviations become `#[expect(lint, reason = "...")]` at the exact spot, so reviewers can judge them.
  </Card>
</CardGrid>
